# Estudos — JavaScript, TypeScript e Node.js

Repositório de acompanhamento dos meus estudos rumo a uma vaga de desenvolvedor.
Ponto de partida: scripting em Lua. Destino: stack JavaScript/TypeScript + Node.js.

Aqui ficam tanto o material dos cursos quanto **todo o código que eu escrevo resolvendo os exercícios** — inclusive as versões que erraram antes de acertar. A ideia é que o histórico de commits mostre a evolução, não só o resultado final.

## Como rodar os exercícios

Requer [Node.js](https://nodejs.org/) instalado.

```bash
node exercicios/curso1_semana1/exercicio_1.5.js
```

Durante a edição, `node --watch <arquivo>` re-executa a cada vez que você salva.
